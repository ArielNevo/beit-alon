# 🏡 בית אלון — ניהול השיפוץ והלבשת הבית

אפליקציית ווב בקובץ אחד (`index.html`) לניהול השיפוץ, מבוססת על קובץ האקסל `renovation_management_app.xlsx`.
עובדת בטלפון ובמחשב, בעברית מלאה, ומשותפת לאריאל, רינת והאדריכלית.

## שלב 1 — העלאה ל-GitHub (בערך 5 דקות)

1. נכנסים ל-[github.com](https://github.com) ← **New repository** ← שם, למשל `beit-alon`.
2. **Upload files** ← גוררים את `index.html`, `README.md` ו-`firestore.rules`.
   > ⚠️ **לא להעלות את קובץ האקסל**: ה-repo יהיה ציבורי.
3. **Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save**.
4. אחרי כדקה האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/beit-alon/`.

בשלב הזה האפליקציה כבר עובדת, אבל במצב **מקומי**: כל אחד רואה רק את מה שהוא עצמו הזין בדפדפן שלו.

## שלב 2 — חיבור לענן לשיתוף בזמן אמת (בערך 10 דקות, חינם)

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) ← **Add project** ← שם `beit-alon`. אפשר לכבות את Analytics.
2. **Build ← Authentication ← Get started ← Sign-in method ← Google ← Enable ← Save**.
3. **Authentication ← Settings ← Authorized domains ← Add domain** ← מוסיפים `<שם-המשתמש>.github.io`.
4. **Build ← Firestore Database ← Create database** ← בוחרים מיקום (למשל `eur3`) ← **Production mode**.
5. **Firestore ← Rules** ← מדביקים את התוכן של `firestore.rules`, **מחליפים את המיילים של רינת והאדריכלית** ← **Publish**.
6. **Project settings (⚙️) ← General ← Your apps ← `</>` (Web)** ← רושמים אפליקציה ← מעתיקים את אובייקט `firebaseConfig`.
7. ב-GitHub פותחים את `index.html` ← ✏️ Edit ← מחפשים את השורה:
   ```js
   const FIREBASE_CONFIG = null;
   ```
   ומחליפים אותה ב-config שהעתקתם:
   ```js
   const FIREBASE_CONFIG = {
     apiKey: "AIza...",
     authDomain: "beit-alon.firebaseapp.com",
     projectId: "beit-alon",
     storageBucket: "beit-alon.appspot.com",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
   ← **Commit changes**.
8. פותחים את האתר ← **התחברות עם Google**. בכניסה הראשונה נתוני האקסל נטענים לענן באופן אוטומטי.
9. שולחים את הקישור לרינת ולאדריכלית. כל אחת מתחברת עם חשבון ה-Google שלה.
10. בהגדרות האפליקציה ← **משתתפים** ← ממלאים לכל אחד את המייל, כדי שהזיהוי יהיה אוטומטי.

> 🔐 **אבטחה:** ה-config של Firebase לא סודי ומותר שיהיה בקוד ציבורי. ההגנה האמיתית היא כללי האבטחה, שמאפשרים קריאה וכתיבה רק למיילים ברשימה. מי שלא ברשימה יראה מסך "אין הרשאה".
>
> כדי להוסיף אדם נוסף (למשל קבלן): מוסיפים את המייל שלו ב-Firestore ← Rules ← Publish.

### העברת נתונים ממצב מקומי לענן
אם כבר עבדתם במצב מקומי: לפני החיבור לענן נכנסים ל**הגדרות ← גיבוי JSON**. אחרי ההתחברות לענן: **הגדרות ← שחזור מגיבוי**.

## שלב 3 — התקנה כאפליקציה בטלפון
- **iPhone (Safari):** כפתור שיתוף ← "הוספה למסך הבית".
- **Android (Chrome):** תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה".

## טיפים לשימוש
- **ישיבה שבועית:** במסך הבית ← "הפקת סיכום לישיבה" ← שליחה לקבוצת הוואטסאפ. בישיבה עוברים על (א) מה נסגר, (ב) החלטות, (ג) השבוע הבא, ואז מעדכנים סטטוסים.
- **קישור למשימה:** בכרטיס משימה ← כפתור השיתוף, ונשלח קישור ישיר אליה.
- **שאלה לאדריכלית:** כותבים הערה בשיחה של המשימה או של הפריט. השינוי יופיע אצלה במסך "מה חדש".
- **אקסל:** אפשר לייצא בכל רגע את כל הנתונים לאקסל (הגדרות ← ייצוא לאקסל). אם עדכנתם את קובץ האקסל המקורי, "עדכון משימות מאקסל" מעדכן משימות לפי ID ושומר את ההערות שנכתבו באפליקציה.
- **בדיקה עתידית:** בהגדרות אפשר לקבוע "היום" לבדיקה, כדי לראות איך הלוח ייראה בתאריך אחר.
- **כלל הבית:** אין רכישה, הזמנה או פנייה לספק בלי אישור מפורש של אריאל.

## פרטים טכניים
- קובץ HTML יחיד, בלי שלב build. JavaScript ו-CSS נקיים, פונטים Heebo ו-Frank Ruhl Libre.
- סנכרון: Firebase Firestore עם מטמון מקומי, כך שהאפליקציה עובדת גם בלי רשת ומסתנכרנת כשהחיבור חוזר. התחברות דרך Google.
- במצב מקומי (כש-`FIREBASE_CONFIG = null`) הנתונים נשמרים ב-localStorage.
- ייצוא וייבוא אקסל: SheetJS, נטען רק בעת הצורך.
- נתוני הפתיחה (משימות, אבני דרך, החלטות וספקים) מוטמעים בקובץ ונטענים בפעם הראשונה בלבד.
